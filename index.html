1. 서비스 개요 및 문제 정의 (기획 배경)

복잡한 영상 편집 소프트웨어(애프터이펙트, 모션그래픽 툴)를 다루지 못하는 초보자도 텍스트 입력과 프리셋 클릭만으로 전문 방송급 모션 타이포그래피를 제작하고 실시간 브라우저 렌더링으로 다운로드할 수 있는 웹 서비스입니다.

구분 상세 내용 (워크시트 4대 질문 프레임워크)
[무엇] 서비스 명칭 편집 초보자를 위한 원클릭 모션 타이포그래피 제작 및 즉시 렌더링 웹앱, "타이포퀵 (TypoQuick)"
[누구] 타겟 사용자 인스타그램 릴스·유튜브 쇼츠·틱톡 입문 크리에이터, 대학생 발표자, 편집 초보자
[왜] 해결하는 문제 영상에 트렌디한 텍스트 모션을 넣고 싶지만 키프레임 그래프나 마스크 등 높은 러닝커브에 좌절하고, 비싼 유료 템플릿에 의존해야 하는 불편함을 해결
[핵심 기능] 3대 기능 1) 텍스트 입력 즉시 실시간 60fps 인터랙티브 프리뷰
2) 바운스, 글리치, 타자기 등 20종 모션 프리셋 원클릭 전환
3) 브라우저 자체 인코딩(WebCodecs)을 통한 투명 배경 WebM/MP4/GIF 3초 고속 렌더링

2. 타겟 페르소나 및 핵심 니즈

타겟 페르소나

이민서 (21세, 대학생 & 숏폼 크리에이터 입문자)

  • 상황: 일상 브이로그와 학과 꿀팁 쇼츠를 제작하고 있으나, 밋밋한 기본 자막 때문에 시청 지속시간(Retention)이 낮아 고민임.
  • Pain Point: 애프터이펙트를 켰다가 복잡한 UI와 렌더큐 설정에 질려 30분 만에 종료함. 캡컷 기본 모션은 너무 흔해서 나만의 개성이 부족함.
  • 핵심 니즈: "문구 입력하고 예쁜 모션 누르면 5초 만에 투명 영상으로 다운받아서 내 영상 위에 바로 얹어 쓰고 싶어요!"

3. 기술적 구현 방향 및 시스템 아키텍처

서버 비용 0원과 딜레이 없는 실시간 60fps 렌더링을 위해 HTML5 Canvas 2D + WebCodecs API 파이프라인을 구축했습니다.

구분 기술 스택 / 방식 도입 이유 및 장점
모션 렌더러 HTML5 Canvas 2D + requestAnimationFrame 글자 단위 분할(Splitting) 및 시간 기반 Easing 보간으로 60fps 실시간 부드러운 애니메이션 구현
동영상 인코딩 MediaRecorder & WebCodecs API 서버로 영상 데이터를 보내지 않고 브라우저 GPU 가속으로 3초 만에 투명 배경 WebM/MP4 즉시 렌더링
폰트 파이프라인 FontFace API & 구글 웹폰트 Pretendard, Black Han Sans 등 상업용 무료 고품질 폰트를 캔버스에 벡터 형태로 지연 없이 로딩

4. 제품 기능 요구사항 (Functional Requirements)

ID 기능 명칭 세부 요구사항 우선순위
FR-01 텍스트 에디터 실시간 문구 입력, 자간 조절, 폰트 드롭다운, 글자 색상 선택 P0 (필수)
FR-02 모션 프리셋 갤러리 바운스, 타자기, 글리치, 네온, 웨이브 등 사전 모션을 원클릭으로 교체 P0 (필수)
FR-03 실시간 타임라인 컨트롤 재생/일시정지, 처음부터 다시, 재생 속도 조절(0.5x~1.5x) P0 (필수)
FR-04 초고속 클라이언트 렌더링 투명 배경 WebM, 일반 MP4, GIF 포맷으로 3초 이내 다운로드 생성 P0 (필수)
